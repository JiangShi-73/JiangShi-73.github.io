「加个动效吧」——这句话通常意味着界面有点死板，但不知道问题出在哪。

我的判断标准很简单：如果一个动效删掉之后，用户会短暂地困惑「刚才发生了什么」，那它就有存在的必要；如果没有困惑，那它只是装饰。

## 三个参数

动效的手感基本由三个参数决定：时长、缓动、位移。

- 时长：小元素 150–250ms，面板 250–400ms，页面级 400–800ms
- 缓动：进入用 ease-out（快起慢停），离开用 ease-in，位移用 cubic-bezier
- 位移：见得到即可。18–24px 足够表达「从下面来」

新手最常犯的错是时长过长。400ms 的按钮反馈，在第三次点击时就已经让人烦躁。

## 状态，而不是表演

好的动效应该解释状态变化：这个面板从哪来、这个按钮被按下了、这条消息是新出现的。

不好的动效在表演：旋转、发光、弹跳，和操作没有因果关系。

## 别忘了关掉它

`prefers-reduced-motion` 不是可选项。前庭功能障碍的用户会因为视差和缩放感到眩晕。

```css
@media (prefers-reduced-motion: reduce) {
  .reveal {
    opacity: 1;
    transform: none;
    transition: none;
  }
}
```

十几行代码，换一部分用户能安心使用你的产品。
